SkyHedge · 完整部署说明

FT5004 Group 5 · 从零开始到 npm start

前置软件安装

在开始之前，确认以下软件已经安装。每项只需安装一次，之后所有项目都可复用。

① Node.js 必须

推荐版本 v18 或 v20（LTS版本）。

1
访问 https://nodejs.org，下载并安装 LTS 版本。
2
安装完成后，打开 PowerShell（Windows）或 Terminal（Mac），验证： 
node --version
npm --version
两行都输出版本号即成功。

② MetaMask 浏览器插件 必须

1
访问 https://metamask.io，在 Chrome 或 Firefox 中安装插件。
2
安装后创建或导入钱包（设置密码，保存助记词）。
⚠️ Windows 用户推荐使用 Firefox + MetaMask，Chrome 在本地开发环境下可能遇到 CSP 安全策略冲突。

③ Git 可选

如果需要从 GitHub 克隆仓库，需要安装 Git。访问 https://git-scm.com 下载安装。

获取项目文件

方式A（收到zip文件）：解压到一个不在 OneDrive / iCloud / 同步盘目录下的位置，例如：

C:\Projects\skyhedge\      # Windows 推荐
~/Projects/skyhedge/       # Mac 推荐
⚠️ 不要放在 OneDrive / iCloud 同步目录下。node_modules 里有数万个小文件，会导致同步软件卡死。

方式B（从 GitHub 克隆）：

git clone https://github.com/你的repo地址/skyhedge.git
cd skyhedge

安装依赖

需要分别为合约（根目录）和前端（frontend目录）各安装一次依赖。

1
打开 PowerShell / Terminal，进入项目根目录： 
cd C:\Projects\skyhedge    # Windows，路径改成你的实际路径
cd ~/Projects/skyhedge     # Mac
2
安装合约依赖（在根目录）： 
npm install
完成后会出现 node_modules/ 文件夹，正常。
3
安装前端依赖（进入 frontend 目录）： 
cd frontend
npm install
cd ..
完成后回到根目录。
✅ 只需要安装一次。之后启动项目不需要重复 npm install，除非 package.json 有变动。

编译合约

在根目录运行：

npx hardhat compile

成功后看到：

Compiled 1 Solidity file successfully

同时会生成 artifacts/ 文件夹，里面包含合约的 ABI 和字节码。

可选：跑测试验证合约逻辑：

npx hardhat test

全部显示 ✓ 即合约逻辑正确。

配置 MetaMask 钱包

① 添加本地测试网络

在 MetaMask 中添加 Hardhat 本地网络：

字段填写内容
Network NameHardhat Local（名字随意）
RPC URLhttp://127.0.0.1:8545
Chain ID31337
Currency SymbolETH

② 导入测试账号

Hardhat 每次启动会生成固定的 20 个测试账号，私钥永不变化。导入以下 5 个：

ℹ️ MetaMask 导入私钥路径：点击右上角账号头像 → Import Account → 粘贴私钥 → 导入。建议给每个账号重命名为对应角色名。

③ 授权所有账号访问网站

连接网页后，在 MetaMask 中进入 Settings → Connected Sites → localhost:3000，将全部 5 个账号都勾选授权，否则切换账号时网页无法识别。

启动本地区块链节点

新开一个 PowerShell / Terminal 窗口，进入根目录，运行：

npx hardhat node

成功后会看到 20 个账号列表和余额，并显示：

Started HTTP and WebSocket JSON-RPC server at http://127.0.0.1:8545/
⚠️ 这个窗口必须保持开启，关掉后本地区块链停止。每次重启电脑或关闭窗口后，都需要重新跑这个命令，并且重新部署合约（见第7步）。

部署合约

新开另一个 PowerShell 窗口（保持节点窗口不关），进入根目录，运行：

npx hardhat run scripts/deploy.js --network localhost

成功后看到：

✅ SkyHedgeCore deployed to: 0x5FbDB2315678afecb367f032d93F642f64180aa3
   Resolver (Oracle) set to: 0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266

复制合约地址（0x5FbDB… 这一串，每次部署都一样）。

更新前端配置

打开 frontend/src/config.js，把第一行改为刚才复制的地址：

export const CONTRACT_ADDRESS = "0x5FbDB2315678afecb367f032d93F642f64180aa3";
✅ 如果你没有重启过节点，合约地址不会变，config.js 不需要修改。只有重启节点后重新部署，地址才可能变化。

启动前端

在根目录或 frontend 目录，运行：

cd frontend
npm start

成功后浏览器自动打开 http://localhost:3000，看到 SkyHedge 界面。

ℹ️ 前端启动后，在 MetaMask 中确认网络切换到 Hardhat Local（Chain ID: 31337），然后点击网页右上角 Connect Wallet，MetaMask 会自动弹出切换网络确认窗口。

每次启动的标准流程

安装完成后，日常启动只需以下步骤：

步骤命令在哪里跑窗口
1. 启动节点npx hardhat node根目录单独窗口，保持开启
2. 部署合约npx hardhat run scripts/deploy.js --network localhost根目录新窗口，跑完可关闭
3. 更新地址把合约地址填入 frontend/src/config.jsVS Code—
4. 启动前端cd frontend && npm start根目录新窗口，保持开启
⚠️ 常见错误：网页报"Contract not found at configured address"。原因是重启了节点但没有重新部署，或部署后没有更新 config.js。按步骤2→3重新操作即可。

（可选）部署到 Sepolia 测试网

Sepolia 是以太坊官方测试网，部署后任何人都可以通过公网访问，无需在本地跑节点。

① 注册 Alchemy，获取 RPC URL

访问 https://dashboard.alchemy.com，注册免费账号 → 创建 App → 选择 Sepolia → 复制 RPC URL（格式：https://eth-sepolia.g.alchemy.com/v2/你的key）。

② 领取 Sepolia 测试 ETH

访问 https://sepoliafaucet.com，输入 Resolver 账号地址，领取免费测试 ETH（每次约 0.1 ETH）。

③ 创建 .env 文件

在根目录复制 .env.example 为 .env，填入：

ALCHEMY_SEPOLIA_URL=https://eth-sepolia.g.alchemy.com/v2/你的key
PRIVATE_KEY_DEPLOYER=0xf39Fd...（Resolver账号私钥）

④ 部署

npx hardhat run scripts/deploy.js --network sepolia

⑤ 更新 config.js 并部署前端

把 Sepolia 合约地址填入 frontend/src/config.js，然后把 frontend 目录推送到 GitHub，在 https://vercel.com 连接仓库自动部署，获得公网 URL。
